# Notices

This add-on adapts stable state semantics and resource-format behavior from
Oritech 1.2.10, GeckoLib, and Athena under their respective permissive
licenses. It bundles none of their models, textures, classes, or binaries;
resources are resolved from the operator-installed exact Oritech JAR.

The BlueMap integration uses the MIT BlueMap 5.23 feature-backport interfaces.
The four MIT Adapter API bootstrap sources are compiled into this add-on from
the exact pinned public source tree. No Adapter API JAR is bundled or nested.
